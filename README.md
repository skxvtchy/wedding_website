# Jonathan & Jasmine — Wedding Website

Next.js (App Router) wedding site with a scroll-rising hot air balloon, guest info sections, and a footer shoe chase.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit content

All names, dates, venue, schedule, registry links, and image paths live in [`lib/content.ts`](lib/content.ts).

## Photos & props

Curated assets used by the site:

- `public/images/couple/` — engagement / portrait photos
- `public/images/party/` — bridal party photos
- `public/images/props/` — balloon, sole, and shoes SVGs

The full local library under `images/` is gitignored; copy chosen files into `public/images/` when you swap art.
